## 🚀 Welcome to VERSION 1
Welcome to the official **V1** release of Dome.

Dome is not a daily driver for reading the news—it is a high-performance workspace engineered specifically for software engineers. We stripped away the consumer bloat and built a browser that solves the actual pain points of web development: managing local environments, testing multiple user roles, and organizing chaotic documentation tabs.

---

## ✨ Developer-First Features

* 🧪 **True Tab Isolation (Multi-User Testing):** Every tab operates as its own isolated container. You can log into your app as an Admin in Tab 1, a User in Tab 2, and a Guest in Tab 3—all in the same window. Say goodbye to juggling 5 different incognito windows just to test role-based access.
* 🖥️ **Dedicated Localhost View:** Stop losing your dev server among StackOverflow tabs. Dome features a separated, persistent view specifically for `localhost` ports, keeping your live development environment instantly accessible and cleanly separated from your research.
* 🗂️ **Contextual Tab Grouping:** Group tabs by project, microservice, or API context. Collapse, expand, and switch entire workspaces instantly without cluttering your top bar.
* ⚡ **DevTools Front & Center:** Built on a lightweight core optimized for heavy DOM inspection and rapid network tab monitoring without eating your RAM.
